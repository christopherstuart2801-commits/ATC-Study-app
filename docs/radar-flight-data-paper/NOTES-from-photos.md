## Overview (paper) — academic vs OJT

- Qual as **radar flight data controller (RFD)**. With ORNT-2000 + sim time → **NAVMC 3500.94** events **RDR-3700**, **QUAL-6100** (enlisted), **QUAL-6103** (officer).
- **Academic phase:** self-guided exercise + PPI test review per test; tests **any order**; **4 weeks**; fam OK; all academic tests before OJT.
- **OJT phase:** min 2 hrs position/day; **6 sequential simulation checklists** (1→6, all items sat before next); OJTI/PPI; all 6 before qual recommend.
- **Important:** overview “**6 checklists**” = **OJT sims**, **not** academic tests. User confirmed **5 academic tests** (Topics 1–5). Topic 6 ACAD-0533 stays on **Finals** until user asks to add to RFD Learn.
