[SRC 6-1-10] FLIGHT PROGRESS STRIPS — block numbering FIG 6-1; examples in Appendix D.
  Standard: Blk1 callsign; Blk2 blank; Blk3 number/type/eqpt + CWT; Blk4 blank; Blk5 beacon.
  Practice / IFR arrivals: Blk7 coord fix or radar-contact position; Blk8 time of radar contact + ✓ inbound to tower; "I" in Blk8 for IMC approaches.
  Blk9: altitude (hundreds); SFA button number with "C" once comms up; radar contact status; remarks.
  Blk10 type apch (13/16 subsequent); Blk11 intentions (14/17); Blk12 bay (15/18 subsequent).
  IFR arrivals: Blk6 previous fix (or inbound airway if handwritten); same 1–5 and 7–12 as practice.
  Tower arrival: Blk15 arrival time; Blk18 flight planning initials.
  IFR departures: Blk2 revision; Blk4 CID; Blk6 P-time; Blk7 req alt; Blk8 dept airport if other than NFG;
    Blk9 clearance limit/route/altitude/remarks + radar contact/handoff; Blk12 "B" when clearance broadcast;
    Blk13 release requested; Blk14 actual release; Blk15 departure time.
  Fallbrook: Blk9 void time as V< time; Blk14 airborne; Blk15 exit Lima.
  Overflight/point-out: Blk9 altitude/remarks/route + large "V" if VFR; Blk17 handoff/pointout facility; Blk18 time.
NOTE (6-1-10): IFR arrivals and VFR practice approaches will not be combined on one strip.

[SRC FIG D-1 / App D-2 / p-156] Tower IFR Flight Strips
==============================================================================
IFR DEPARTURE template fields (tower):
  CALLSIGN | TYPE/EQPT | CODE | P-TIME | REQ ALT | DEPT POINT |
  CLEARANCE LIMIT, ROUTE OF FLIGHT / REMARKS (+ REQ RLS, RLS TIME; DEPARTURE FREQ IF OTHER THAN PUBLISHED) |
  CLNC ISSUED | DEPT TIME | FLT PLNG

Examples transcribed from figure:
1) ATLAS40 · H/UH1Y/P · 4774 · P1900 · 60 · NFG
   Route: NFG QUNTN1 QUNTN SKATE NZY · ↑30
   REQ RLS 1900 · RLS TIME 02 · CLNC ISSUED B · DEPT TIME 04 · FLT PLNG CA
2) ATLAS22 · H/SUCO/P · 7252 · P2300 · OTP/40 · NFG
   Route: NFG BLDG2 VISTA · ↑ OTP/40
   REQ RLS 2303 · RLS TIME 05 · CLNC ISSUED B · DEPT TIME 05 · FLT PLNG RP
   Label: IFR EAST LOCAL VFR-ON-TOP STRIP - VISTA
3) SWIFT13 · G/V22/I · 4540 · P1600 · OTP/38 · NFG
   Route: NFG CORRI3 CORRI · ↑ OTP/38
   REQ RLS 1558 · RLS TIME 1601 · CLNC ISSUED B · DEPT TIME 02 · FLT PLNG RP
   Label: IFR LIMA VFR-ON-TOP STRIP RWY 21 - CORRI
4) SWIFT22 · G/V22/I · 4543 · P1730 · OTP/38 · NFG
   Route: NFG CORRI3 CORRI · ↑ OTP/38
   REQ RLS 1732 · RLS TIME 35 · CLNC ISSUED B · DEPT TIME 37 · FLT PLNG RP
   Label: IFR LIMA VFR-ON-TOP STRIP RWY 3 - CORRI

IFR ARRIVAL template (tower):
  CALLSIGN | TYPE/EQPT | CODE | PREVIOUS FIX | COORD FIX | ETA AT COORD FIX |
  INTENTIONS / REMARKS | ARR TIME | FLT PLNG

[SRC FIG D-5 / App D-6 / p-160] Radar Arrival Strips
==============================================================================
IFR ARRIVAL template:
  CALLSIGN | TYPE/EQPT | CODE | PREVIOUS FIX | COORD FIX |
  ETA AT COORD FIX | ACTUAL IFR | INBOUND PASSED |
  ALTITUDE | RADAR CONTACT/HANDOFF (C / SFA marking in block) |
  TYPE APCH | INTENT | BAY  (three rows for multiple approaches)

Example IFR arrival:
  STMPD19 · I/B350/L · 2252 · SXC · OCN · 1745 · I · ✓ inbound
  Altitudes: <s>50</s> <s>40</s> 24 · C7 (SFA button; "C" around frequency once checked in) · circled R
  TYPE APCH: TZ (figure shows TZ; instructional note: checkmark through once cleared) · INTENT FS · BAY 1
Figure notes:
  "PUT A CHECKMARK THROUGH THE TYPE APPROACH ONCE THE AIRCRAFT IS CLEARED."
  "FOR IFR AIRCRAFT, PLACE I IN BOX 8."

IFR MULTIPLE GCA ARRIVAL (handwritten) example:
  ATLAS40 · H/H1/P · 4534 · RADAR ID FIX L18 3N · TIME 2022 · I · ✓
  Altitude rows: 28/28/28 · <s>32</s>/20/24 · 24 · C3 · circled R / circled R / R
  APCH rows: PA/LAR/1 · PA/LAR/2 · SA/LAZ/1 as printed (figure note: checkmark through TYPE APCH once cleared — IFR arrival figure shows plain TZ; multi-GCA PA rows unstruck)
  Note: "PUT A 'C' AROUND THE FREQUENCY ONCE THE AIRCRAFT CHECKS IN ON THAT FREQUENCY."

NON-RADAR ARRIVAL example:
  Template Block 3 is TIME AT ID FIX + INBOUND TO TOWER only (no ACTUAL IFR box — unlike IFR arrival).
  ATLAS40 · H/H1/P · 4534 · FREQ circled 4 · RADAR ID FIX L18 3N · TIME 2022 · ✓ inbound to tower
  Altitudes <s>50</s> <s>40</s> 28 · optional Blk9 RADAR ID STATUS marks as shown (CU/42 · 1910/1915 · R struck)
  TYPE APCH: <s>PA</s> TZ · INTENT FS · BAY 1
  Note: "NON-RADAR CONTROL MARKINGS SHOWN IN BLOCK 9 ARE OPTIONAL."

[SRC FIG D-6 / App D-7 / p-161] Other Radar Strips
==============================================================================
OVERFLIGHT template fields:
  CALLSIGN | TYPE | CODE | RADAR ID FIX | TIME AT ID FIX |
  ROUTE THROUGH LIMA AIRSPACE / ALTITUDE (+ RADAR CONTACT / HANDOFF) |
  HANDOFF FACILITY | HANDOFF TIME
Example: N23485 · PA34 · 0252 · TANNR · 1745 · TANNR-CRQ · 45 · large V · circled R · HANDOFF FACILITY RIV · HANDOFF TIME 1756
  Note: write a large V in Blk9 if VFR; otherwise IFR.

POINT OUT template fields:
  CALLSIGN | TYPE/EQPT | CODE | RADAR ID FIX | TIME ENTERING LIMA |
  ROUTE THROUGH LIMA AIRSPACE / ALTITUDE | POINTOUT FACILITY | EXIT LIMA
Example: N4282M · SR22 · 0255 · OCN · 2022 · OKB–F70 · 45 · large V · POINTOUT FACILITY PSCT · EXIT LIMA 2030
  Note: write a large V in Blk9 if VFR; otherwise IFR.

FALLBROOK DEPARTURE template fields:
  CALLSIGN | TYPE | CODE | P-TIME | REQ ALT | DEPT POINT |
  ROUTE OF FLIGHT, CLEARANCE LIMIT / CLEARANCE VOID TIME | DEP TIME | EXIT LIMA
Example: N234WC · 2/AV8 · 5646 · P1800 · 60 · L18
  Route ROBNN OCN V23 LAX V299 VTU VTU299R SBA · CLEARANCE VOID TIME V<1810 · DEP 1811 · EXIT LIMA 1812
